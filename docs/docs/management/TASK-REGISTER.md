
# FlowCanvas Task Register

This file is the shared source of truth for task ownership and progress.

## Status Definitions
- Backlog: Not yet ready to start.
- Ready: Requirements and scope are clear.
- In Progress: Work has started.
- In Review: Submitted for review.
- Blocked: Waiting for information or another task.
- Done: Acceptance criteria have been met and work reviewed.

## Rules
- Assign one primary owner to each task.
- Define the expected deliverable and acceptance criteria before work begins.
- Confirm deadlines with the team.
- Record important dependencies and shared-design changes.
- Do not mark a task Done without reviewing its deliverable.
