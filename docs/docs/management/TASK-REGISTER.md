# FlowCanvas — Task Register

## Purpose

This register provides a shared overview of project tasks, ownership, status, and expected deliverables.

GitHub Issues and GitHub Projects will be used for active task tracking.

## Status Definitions

- **Backlog:** Task not yet ready to start.
- **Ready:** Task is clear and ready to begin.
- **In Progress:** Work has started.
- **In Review:** Work is awaiting review.
- **Blocked:** Work cannot proceed due to a dependency or unresolved issue.
- **Done:** Deliverable is completed and reviewed.

## Task Management Rules

1. Each task must have a clear owner before implementation begins.
2. Each active task should have a corresponding GitHub Issue.
3. Task status must be kept consistent with the GitHub Project board.
4. Use dedicated branches for features and bug fixes.
5. Use clear, meaningful commit messages.
6. Review work before marking a task Done.
7. Update this register when task ownership or major deliverables change.

## Notes

This is an initial planning register. Tasks, owners, and statuses may change after team discussion and confirmation of project requirements.
